# 测试页面说明

这是 Custom Meting API 的测试网页，用于测试 API 的各项功能。

## 访问方式

启动服务后，在浏览器中访问：

```
http://localhost:9526/test/
```

## 功能说明

### 1. **刷新歌单** - 重新获取当前时段的歌单
### 2. **获取服务状态** - 查看服务的运行状态和当前时段
### 3. **清空缓存** - 清除歌单缓存
### 4. **播放歌曲** - 点击歌曲卡片可以播放音频
### 5. **歌词显示** - 如果歌曲有歌词，会在播放时显示歌词

## 测试内容

测试页面会显示：
- 当前时段的歌单
- 歌曲封面图片
- 歌曲和
- 播放功能
- 歌词显示
